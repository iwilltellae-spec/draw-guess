# 🎨 Рисуй & Угадай — Telegram Web App для двоих 💕

Мультиплеер-игра: один рисует слово, другой угадывает в чате. Реалтайм между
двумя телефонами через WebSocket. Милый стиль, адаптация под мобильные,
интеграция с Telegram Web App.

```
draw-guess/
├── public/        ← фронтенд (статика) → деплой на Vercel / Netlify
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   └── words.js
└── server/        ← Socket.IO сервер → деплой на Render.com
    ├── server.js
    └── package.json
```

---

## 1. Локальный запуск (проверить на компьютере)

### Сервер
```bash
cd server
npm install
npm start          # сервер на http://localhost:3000
```

### Фронтенд
В отдельном терминале:
```bash
cd public
npx serve .        # или: python3 -m http.server 8080
```
Открой `http://localhost:8080` в двух вкладках (или вкладка + телефон в той же
Wi-Fi сети по локальному IP). Создай комнату в одной, введи код во второй —
играйте!

> В `index.html` уже стоит автоопределение: на localhost клиент стучится на
> `http://localhost:3000`.

---

## 2. Деплой в прод

### Шаг А. Сервер на Render.com (бесплатно, держит WebSocket)
1. Залей папку `server/` в репозиторий GitHub.
2. На render.com → **New → Web Service** → подключи репозиторий.
3. Настройки:
   - **Root Directory:** `server`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. Получишь адрес вида `https://draw-guess-xxxx.onrender.com`.

> ⚠️ Бесплатный Render «засыпает» после простоя — первый запуск может занять
> ~30 сек. Для пары это норм.

### Шаг Б. Фронтенд на Vercel/Netlify
1. В `public/index.html` найди строку и впиши свой Render-адрес:
   ```js
   : "https://ЗАМЕНИ-НА-СВОЙ.onrender.com";
   ```
2. Залей папку `public/` на Vercel (drag-and-drop в дашборде или через GitHub).
3. Получишь HTTPS-ссылку вида `https://draw-guess.vercel.app`.

---

## 3. Подключение к Telegram-боту

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → создай бота.
2. `/newapp` (или `/setmenubutton`) → выбери бота → укажи URL твоего
   фронтенда (Vercel-ссылку).
3. Готово! Кнопка меню бота откроет игру внутри Telegram.
   - Ты открываешь со своего телефона → «Создать комнату».
   - Девушка открывает того же бота → вводит код. Играете 💕

---

## 4. Как настраивать игру

- **Слова:** `public/words.js` (для UI) и массив `WORDS` в `server/server.js`
  (для логики — именно отсюда берётся загаданное слово). Добавляй свои общие
  воспоминания в раздел «love» — будет особенно мило.
- **Длительность раунда / число раундов / очки:** константы вверху
  `server/server.js` (`ROUND_TIME`, `TOTAL_ROUNDS`, `POINTS_GUESS`, `POINTS_DRAW`).
- **Цвета палитры:** массив `PALETTE` в `public/app.js`.
- **Стиль/цвета оформления:** CSS-переменные в начале `public/style.css`.
