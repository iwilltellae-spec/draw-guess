# 🚀 Как выложить игру в интернет и сделать Telegram WebApp
### Инструкция «для новичка», по шагам. Не торопись, делай по порядку.

---

## 📦 Что вообще происходит (на пальцах)

Наша игра состоит из ДВУХ частей:

1. **Папка `public/`** — это «лицо» игры (то, что видно: кнопки, холст, цвета).
   Её мы положим на **Vercel**.
2. **Папка `server/`** — это «мозг» игры (соединяет два телефона, считает очки).
   Её мы положим на **Render**.

Обе части мы сначала зальём на **GitHub** (это «склад кода»), а потом
Vercel и Render возьмут код со склада.

👉 Порядок такой:
**GitHub → Render (мозг) → Vercel (лицо) → Telegram-бот.**

Делаем строго в этом порядке. Поехали!

---

## ШАГ 1. Загружаем код на GitHub

1. Скачай папку проекта `draw-guess` себе на компьютер (всю целиком).
2. Зайди на сайт **https://github.com** и войди в свой аккаунт.
3. Справа вверху нажми на **➕** → **New repository** (новый репозиторий).
4. В поле **Repository name** напиши, например: `draw-guess`
5. Выбери **Public** (публичный — так надо для бесплатных хостингов).
6. Нажми зелёную кнопку **Create repository**.
7. Откроется страница репозитория. Найди ссылку
   **«uploading an existing file»** (или кнопку **Add file → Upload files**).
8. Теперь ОТКРОЙ папку `draw-guess` у себя на компьютере и **перетащи мышкой
   ВСЁ её содержимое** (папки `public`, `server` и файлы) в окно браузера.
   - Подожди, пока всё загрузится (внизу будет видно прогресс).
9. Внизу нажми зелёную кнопку **Commit changes**.

✅ Готово! Твой код теперь на GitHub. Это твой «склад».

---

## ШАГ 2. Запускаем «мозг» (сервер) на Render

1. Зайди на **https://render.com** → **Get Started** → войди через **GitHub**
   (нажми «Continue with GitHub», разреши доступ).
2. В панели нажми **New +** → выбери **Web Service**.
3. Render попросит подключить репозиторий → найди свой `draw-guess` →
   нажми **Connect**.
4. Откроются настройки. Заполни так:
   - **Name:** любое, например `draw-guess-server`
   - **Region:** оставь как есть (или Frankfurt — он ближе к нам)
   - **Branch:** `main`
   - **Root Directory:** впиши `server`   ⬅️ ВАЖНО! именно `server`
   - **Runtime / Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type / Plan:** выбери **Free** (бесплатный)
5. Нажми **Create Web Service** (или **Deploy**).
6. Подожди 2–4 минуты. Когда увидишь надпись **«Live»** и зелёную точку —
   сервер работает! 🎉
7. Вверху страницы будет **адрес твоего сервера**, например:
   `https://draw-guess-server-xxxx.onrender.com`
   👉 **СКОПИРУЙ этот адрес — он понадобится в Шаге 3!**

> 💡 Проверка: открой этот адрес в браузере. Должна появиться надпись
> «Draw & Guess server is running 💕». Значит всё хорошо.

> ⚠️ На бесплатном Render сервер «засыпает» после 15 минут без игры.
> Когда вы заходите снова — он «просыпается» ~30 секунд (первый экран может
> чуть подвиснуть). Для игры вдвоём это нормально.

---

## ШАГ 3. Вписываем адрес сервера в игру

1. Зайди на GitHub в свой репозиторий `draw-guess`.
2. Открой папку **`public`** → нажми на файл **`config.js`**.
3. Нажми на **карандашик ✏️** (Edit this file) справа вверху.
4. Найди строку:
   ```
   const MY_SERVER = "ВПИШИ_СЮДА_АДРЕС_СЕРВЕРА";
   ```
5. Замени текст в кавычках на адрес из Шага 2. Должно стать так
   (адрес у тебя будет свой!):
   ```
   const MY_SERVER = "https://draw-guess-server-xxxx.onrender.com";
   ```
   ⚠️ Кавычки оставь! Адрес — без слэша `/` на конце.
6. Внизу нажми **Commit changes** → **Commit changes**.

✅ Готово. Теперь «лицо» игры знает, где живёт «мозг».

---

## ШАГ 4. Выкладываем «лицо» игры на Vercel

1. Зайди на **https://vercel.com** → **Sign Up / Log in** через **GitHub**.
2. Нажми **Add New...** → **Project**.
3. Найди свой репозиторий `draw-guess` → нажми **Import**.
4. Откроются настройки. Главное:
   - **Root Directory:** нажми **Edit** и выбери папку **`public`**  ⬅️ ВАЖНО!
   - **Framework Preset:** оставь **Other** (или «No framework»).
   - Остальное не трогай.
5. Нажми **Deploy**.
6. Подожди ~1 минуту. Появятся фейерверки 🎉 и кнопка **Visit** /
   адрес вида `https://draw-guess-xxxx.vercel.app`
   👉 **СКОПИРУЙ этот адрес — это и есть твоя игра!**

> 💡 Проверка: открой этот адрес на телефоне. Должно открыться лобби игры.
> Можешь даже сразу проверить вдвоём: на своём телефоне «Создать комнату»,
> на телефоне девушки открыть тот же адрес и ввести код.

---

## ШАГ 5. Делаем из этого Telegram WebApp (через бота)

1. В Telegram найди **@BotFather** (официальный, с галочкой) и открой чат.
2. Отправь команду: `/newbot`
3. BotFather спросит:
   - **имя бота** (любое, например «Рисуй и Угадай») — напиши и отправь.
   - **username бота** — должен заканчиваться на `bot`, например
     `draw_guess_love_bot`. Если занято — придумай другой.
4. BotFather пришлёт сообщение с **токеном** (длинная строка). Просто сохрани
   его, для WebApp он не обязателен, но пусть будет.
5. Теперь привяжем нашу игру к кнопке бота. Отправь BotFather: `/newapp`
   - Выбери своего бота из списка.
   - **Title** — название, например «Рисуй и Угадай».
   - **Description** — короткое описание, например «Игра для двоих».
   - **Photo** — попросит картинку 640×360. Можешь пропустить (отправь
     `/empty`) или загрузить любую.
   - **GIF** — тоже можно пропустить (`/empty`).
   - **Web App URL** — ВОТ СЮДА вставь адрес из Шага 4
     (`https://draw-guess-xxxx.vercel.app`).
   - **Short name** — короткое имя латиницей, например `play`.
6. Готово! BotFather даст ссылку вида `https://t.me/твой_бот/play`.

### Чтобы игра открывалась кнопкой «меню» в боте:
1. Отправь BotFather: `/mybots` → выбери своего бота.
2. **Bot Settings** → **Menu Button** → **Configure Menu Button**.
3. Вставь адрес игры с Vercel и задай текст кнопки, например «🎨 Играть».

---

## 🎉 ВСЁ! Как теперь играть вдвоём

1. Ты открываешь своего бота в Telegram → жмёшь кнопку «🎨 Играть».
2. Вводишь имя → «Создать комнату» → получаешь КОД.
3. Девушка открывает того же бота на своём телефоне → «🎨 Играть» →
   вводит имя и КОД → «Войти».
4. Играете! 💕

## ❓ Если что-то не работает

- **«Не получается подключиться к серверу»** — скорее всего:
  - сервер на Render ещё «просыпается» (подожди 30 сек и обнови),
  - или в `config.js` неправильный адрес (проверь Шаг 3: без `/` на конце,
    в кавычках).
- **Открыл игру — белый экран** — проверь, что в Vercel в **Root Directory**
  выбрана папка `public` (Шаг 4).
- **Изменил код на GitHub, а в игре по-старому** — Vercel и Render
  автоматически пересобирают проект после изменений на GitHub. Подожди
  1–2 минуты и обнови страницу (на телефоне — закрой и открой WebApp заново).

Удачи! Если застрянешь на каком-то шаге — скажи мне, на каком именно,
и что именно видишь на экране. 🙂
